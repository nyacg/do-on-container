Bindings example

An AI chat room, written as a plain Durable Object

Each room is one Durable Object. It runs every message through a moderation Worker, answers with Workers AI (when you start with @ai, or when nobody else is chatting; repeat questions come from KV), keeps attachments in R2, and reports to a Lobby Durable Object. Run it as a real DO or pooled in a container: the code is the same, and so are the calls. Under each message you can see which bindings it used and how long each call took.

    // objects/ai-room.ts (excerpt)

// another Worker (named entrypoint)
const clean = await this.env.MODERATOR
  .moderate(text);

// KV, then another DO, then Workers AI
let answer = await this.env.KV.get(key);
if (!answer) {
  await this.env.LOBBY
    .getByName("global").takeAiBudget();
  answer = (await this.env.AI.run(MODEL,
    { messages })).response;
  await this.env.KV.put(key, answer,
    { expirationTtl: 3600 });
}

// R2
await this.env.FILES.put(id, bytes);
